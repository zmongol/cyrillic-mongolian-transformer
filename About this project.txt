This repository contains a bidirectional Transformer-based character-level model for Cyrillic ↔ Traditional Mongolian script transformation.

Unlike rule-based converters or heuristic mappings, this project uses a full neural sequence-to-sequence Transformer trained on aligned parallel text, enabling:

Robust handling of contextual glyph variants

Noise tolerance in real-world text

Extendability to OCR, IME, and NLP pipelines

The system is trained in both directions:

Cyrillic → Traditional Mongolian

Traditional Mongolian → Cyrillic

Each direction is trained independently using a shared architecture but separate vocabularies.
